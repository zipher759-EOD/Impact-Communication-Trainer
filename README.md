# IMPACT Communication Trainer

ADHD-friendly articulation and concise communication training game.

## GitHub Pages

Publish from the repository's `main` branch and `/ (root)`. All PWA paths are relative so the app works under a project URL such as `https://USERNAME.github.io/impact-communication-trainer/`.

## Files

- `index.html` - complete app
- `manifest.webmanifest` - installable PWA metadata
- `sw.js` - offline app shell caching
- `icon-192.png` and `icon-512.png` - PWA icons
