# Impact Communication Trainer

A private, offline-first communication practice app built as a static Progressive Web App (PWA).

## What it trains

- Clear thinking and structure
- Concise delivery
- Articulation and diction
- Presence and vocal impact
- Precision language
- Professional/work communication

## Features

- Daily, quick, deep, shuffle, and work-focused practice modes
- Timed drills with optional coach guidance
- Optional in-browser voice recording and playback
- XP, daily reps, ratings, and streak tracking stored locally in the browser
- No accounts, analytics, cloud storage, or audio uploads
- Installable PWA with offline app-shell support

## Files

- `index.html` - complete app
- `manifest.webmanifest` - PWA metadata
- `sw.js` - offline service worker
- `icon-192.png` / `icon-512.png` - install icons

## GitHub Pages

This repository is a static site and can be served directly from the repository root with GitHub Pages.
